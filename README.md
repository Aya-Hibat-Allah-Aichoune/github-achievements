# 🏆 GitHub Achievements

A small playground repo I used to learn how GitHub profile **Achievements** work.

## Unlocked

| Achievement | How |
|---|---|
| ⚡ Quickdraw | Opened and closed an issue within 5 minutes |
| 🎲 YOLO | Merged a pull request without a review |
| 🦈 Pull Shark | Merged pull requests (working up the tiers: 2 → 16 → 128 → 1024) |

## In progress

- 🌟 **Starstruck** — needs 16 stars on a repo. If this helped you, a ⭐ helps me get there!
- 🧑‍🤝‍🧑 **Pair Extraordinaire** — needs a co-authored commit in a merged PR
- 🧠 **Galaxy Brain** — needs 2 accepted answers in Discussions

## How achievements work

GitHub awards them automatically — you can't add them manually.
They appear in the **Achievements** section of your profile once earned.
